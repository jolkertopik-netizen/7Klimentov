# Система заказов компании «Мебель-Дом»

**Автор:** Климентов Д.В, группа И-43

## Что делает программа

- Рассчитывает цену со скидкой 15% для товаров без заказов в прошлом месяце
- Выводит размер скидки и итоговую цену в консоль
- Демонстрирует работу метода `GetDiscountedPrice`
- Выводит фамилию автора и номер группы

## Как запустить

1. Открыть файл `src/Lab7Klimentov.sln` в Visual Studio
2. Нажать F5
3. В консоли появится результат расчёта
